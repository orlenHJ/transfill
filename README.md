# TransFill 译填

看中文，填英文单词，练习英语翻译能力。

## 使用方法

1. 双击 `启动练习.bat`，浏览器会自动打开
2. 选择难度等级（初级/中级/高级），开始练习
3. 根据中文提示，填写英文空缺单词，按回车或点击"检查"

## 前提条件

需要安装 [Node.js](https://nodejs.org/)（下载 LTS 版本，一路下一步安装即可）。

## AI 生成句子（可选）

默认使用内置的 100 句常用句库。如需 AI 生成无限新句子：

1. 打开页面后点击顶部的"设置"
2. 在 API Key 栏填入你的 DeepSeek API Key
3. 点击"保存设置"

API Key 获取方式：注册 https://platform.deepseek.com/ ，在 API Keys 页面创建。

## 功能按钮

- **检查** - 提交答案，判断对错
- **提示** - 逐字母提示当前空格的答案
- **下一个** - 跳到下一句
- **标记** - 收藏句子到复习列表
- **显示答案** - 直接显示完整答案

## 文件说明

